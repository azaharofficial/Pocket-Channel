☁ Google Drive Sync Setup

  1. Open Google Cloud Console and create or select a project.
  2. Enable the Google Drive API under APIs & Services.
  3. Configure the OAuth Consent Screen (External) and add your Gmail under Test Users.
  4. Go to Credentials → Create Credentials → OAuth Client ID → Web application.
  5. Add your app origin below under Authorized JavaScript origins, copy the Client ID, paste it here, and tap Connect.
